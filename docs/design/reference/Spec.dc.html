Locke · behaviour

Interaction spec

How people move around, what they see while a job travels from submit to result, and how touch, keyboard and assistive tech drive it.

1 · Navigation

Create → Jobs (toast "View", indicator) → Characters (picker, "New") Landing tab. Keeps the last prompt and settings.
Jobs → Job result → full-screen viewer → Editor ("Use in editor") → Create, prefilled ("Run again", "More like this")
Editor Pick (vault / source / upload) → item workspace → Jobs (pending version links to its job) → Characters (face swap "New")
Characters Grid → edit (dialog on mobile, panel on desktop) "Used in" → Jobs filtered by character "Create with…" → Create, preselected
Settings Mobile: avatar in the header Desktop: sidebar footer "Open vault" leaves to Locke Vault
Automate List → workflow builder Sources come from Jobs › Scheduled, iCloud, Generated… One result per image · blur removable
Global job indicator

Header pill (mobile) / sidebar card (desktop): "2 running · 3 queued". Tap → Jobs, scrolled to the active group. Hidden when nothing is in flight; a dot on the Jobs tab marks unseen results.

State survives navigation

Each tab keeps its scroll position and draft. Leaving Create mid-prompt never loses text; the draft is stored encrypted, on the device.

Deep links

/jobs/:id, /editor/:itemId?v=3, /characters/:id. Notifications open the exact job result.

2 · Job lifecycle feedback

Submit

Button press 120 ms, then reset at once. Toast "Queued · 3rd in line · View". Form keeps its values. Indicator +1. Focus stays on the prompt.

Queued

Row enters at the top (fade + 8 px rise, 200 ms). Shows position in line, updated live. No toast for position changes.

Waiting for GPU

Only if the worker is offline. One calm card on Jobs; rows say "Waiting". No toast, no badge, no red. Resumes on its own.

Running

Percent when the worker reports steps; otherwise indeterminate bar + "Running". No image preview — jobs are sealed on the partner side; the thumbnail stays the style or source image.

DoneFailedExpired

Done: toast with thumbnail + "Open"; dot on Jobs tab; push notification only if Locke is in the background. Failed: toast with the plain-language reason + "Retry"; nothing was changed. Expired: after the keep period; row stays with parameters and "Run again".

Private notifications. Push and lock-screen text never contains the prompt, a character name or an image: "Locke · 4 results are ready". Opt-in, asked after the first finished job — not at launch.

One line of history, reversible blur. Enhance and face swap always apply in order. Blur is always the last step: the image just before blur is kept, so "Remove blur" is a one-tap rollback. A tool run on a blurred image applies underneath, then blur is re-applied.

3 · Mobile gestures

Swipe ← →Next / previous variant in the viewer; follows the finger, snaps at 30 % or a fast flick. Off while zoomed.
Pinch · double-tapZoom 1× – 4× around the fingers; double-tap toggles 1× / 2.5×. One finger pans when zoomed. Same on the editor canvas.
Swipe downCloses the full-screen viewer (image shrinks back into its tile).
Bottom sheetsDetents at 45 % and 92 %. Drag the grabber or content top; swipe down or tap the scrim to dismiss. Editor tools sheet never fully closes — it collapses to its tool tabs.
Long-pressTiles and job rows: enter multi-select. Face photos: lift to reorder. Prompt excerpts: show full text.
CompareDrag anywhere on the image to move the split; press and hold the compare button to peek at the original.
Edge swipeiOS back gesture is preserved in standalone mode; pull-to-refresh only on Jobs.

4 · Keyboard & assistive tech

Ctrl / ⌘ + EnterGenerate from the prompt field.
← → · EscVariants in the viewer; Esc closes viewer, sheets and dialogs and returns focus to the trigger.
K · D · DeleteKeep, download, discard the focused variant (discard has 5 s Undo).
Live regionsPolite announcements: "Job queued, 3rd in line", "4 results ready", "GPU offline, 3 jobs waiting". Progress percent is not announced continuously.
CharactersBubbles are toggle buttons ("Ana, selected"). Face matching is automatic on the partner side, using each character's gender and age.
Compare sliderrole="slider"; arrow keys move 10 %, Home / End jump to before / after.
ToastsNever steal focus; 5 s, paused on hover or focus; the action is also reachable from Jobs.

5 · Prompts, schedules & workflows

Prompt editor

List mode splits on commas: each fragment is numbered, toggled with a switch, drag-reordered, edited in place. Raw mode is the same text, joined. Flip moves the selected fragment (or the whole view) to the negative prompt. Saving names the prompt; saved prompts keep their schedule.

References & run

Up to 4 references from the vault or an upload, numbered in order. "Run now" queues one job; "Schedule" asks for a name and a cadence (every minute, hourly, daily, weekly). Each schedule appears in Jobs › Scheduled and as a vault source named after it.

Workflows

A workflow watches one or more sources and runs its steps in order on every new image — one result per image. Blur, if on, is pinned as the last step and keeps the pre-blur copy, so it can be removed later on any result. A failing image never stops the workflow; it shows in Activity with Retry.

6 · Tablet behaviour

Portrait (768–1023)

Nav rail. Create is one column with presets in a 4-column grid. Job result opens full page; editor tools are a right side sheet over the canvas.

Landscape (1024+)

Desktop layout with the collapsed 72 px rail; Jobs list + result split; editor tools panel docked.

Input

Touch sizes stay 44 px even in the desktop layout on tablets; the "sm" pointer sizes switch on only with (pointer: fine).
