Locke design system

Layout, shells & breakpoints

One information architecture, three shells. Navigation moves from a bottom tab bar to a rail to a sidebar; the job indicator is always one tap away; the bottom-right corner always belongs to the platform assistant.

Sidebar holds nav, the job indicator, worker status and vault quota. Context panels end 96 px above the bottom so the assistant never covers an action. Between 1024 and 1279 the sidebar collapses to a 72 px rail.

Assistant corner

Reserved: right: 0; bottom: 0; 88 × 88 plus env(safe-area-inset-bottom). No primary actions, toasts, FABs or pagination there.

Sticky action bars (Generate, Run tool) end at right: 88px on compact, and sit in the content column on expanded.

Its chat panel overlays Locke; Locke does not resize for it.

Home-screen web app

display: standalone, viewport-fit=cover. Headers add safe-area-inset-top; the tab bar adds the bottom inset + 8 px.

theme-color follows the active theme (#0E0F11 / #F5F5F6). No pull-to-refresh on screens with canvases; Jobs refreshes live.

Back = in-app header back button (no browser chrome); edge-swipe back on iOS is preserved.
