Locke
Design system · v1.0 · Foundations

A calm studio for private image making.

Dark-first, image-first. Quiet navy-grey surfaces, pill-shaped controls, mint for what you do and blue for what you chose, and small lock cues instead of alarms. Every value below is a CSS custom property in locke.css; switching theme is one class on the root.

01

Images are the hero

Chrome recedes: neutral surfaces, thin borders, controls float over images only when needed.

02

Waiting is normal

Jobs run in the background. Submit, leave, come back. No blocking spinners, ever.

03

Private, quietly

Small lock cues where data lives: prompts, vault, characters. Never banners, never fear.

04

Mint to do, blue for chosen

Mint = primary actions and toggles. Blue = selected pills and work in progress. Nothing else is coloured.

Rules

Inter carries all UI text: wide Latin coverage (French accents, ligatures), tabular figures for counts, sizes and times.

Space Grotesk only for screen titles and display — never for buttons or body.

Overline is the only uppercase style. Buttons and tabs stay sentence case so translations don't shout.

Labels may wrap to 2 lines; nothing is fixed-width. Budget +40% length for French.

Dates, sizes and counts come from Intl.DateTimeFormat, Intl.NumberFormat and Intl.RelativeTimeFormat — "2 min ago" / "il y a 2 min".

Reduced motion

Slides, zooms and sheet travel become a 120 ms crossfade.

Indeterminate progress becomes a static, half-opacity bar plus the text "Running".

Skeleton shimmer is off; skeletons stay as flat shapes.

Swipe between variants still works, but snaps without momentum animation.

Result arrival never bounces or pulses: a 200 ms fade-in of the thumbnail and a toast.

Indeterminate · animates only without prefers-reduced-motion
